## 安装与维护

初始化或升级项目后，在 server 目录填写 `.env`，核对 DB_NAME，然后执行：

```powershell
npm.cmd run catalog:import -- --dry-run
npm.cmd run catalog:import -- --seller moya
```

导入不会创建卖家账号，不修改已有条目。标识与商品绑定；再次运行保留管理端已修改的标题、价格和状态。管理员在后台“商品管理”可以上下架，在网站“我的发布”可以编辑商品内容。单件商品删除后再次执行导入会补回该条；若不想继续展示，使用下架即可。

改动 JSON 不会自动覆盖数据库中的已导入商品；日常调整请从管理界面编辑。迁移到新服务器时，完整迁移现有数据库和 uploads，或在新库执行内容导入；源码与 web/dist 不能替代数据库。
